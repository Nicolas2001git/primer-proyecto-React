Es un proyecto que estoy desarrollando donde se utiliza React junto a componentes, rutas, estado y un poquito de diseño. La idea es simular una web donde uno puede reservar expediciones a distintos lugares de la Tierra Media (El Señor de los Anillos). 
El usuario puede iniciar sesión con un nombre, ver una lista de destinos como Mordor, Rivendel, Moria, etc., y entrar al detalle de cada uno. Ahí puede elegir un guía obligatorio antes de agregar el viaje al carrito. El carrito muestra cuántos destinos se agregaron. También agregué una sección de Contacto donde aparecen tres personajes conocidos y se les puede ver una puntuación con estrellas, usando Ant Design 
Estoy usando:
-React + React Router
-Ant Design para mejorar algunos componentes visuales
-CSS hecho por mí para darle una onda temática medieval
